# 🤝 Contributing to VOXA / VOXA

Thank you for your interest in contributing to **VOXA**! We welcome community contributions to our public frontend UI shell, components, and integrations.

---

## 🪡 Open Core & Contribution Scope

VOXA operates under an **Open Core Commercial Model**:

- ✅ **Public Contributions Accepted**:
  - Frontend UI components (React Native / NativeWind)
  - Navigation flows and layout themes
  - Bug fixes in public tools or UI components
  - Community documentation & guides

- 🔒 **Private Core Systems (Not in Public Repo)**:
  - Native Kotlin/C++ voice engine and PCM audio pipelines
  - Production agentic orchestration & tool loops
  - Security, license validation, and anti-tamper modules

> 💡 **For source code access, commercial licensing, or custom enterprise development**, please contact the developer directly at **`voxaaidevop@gmail.com`**.

---

## 🚀 How to Contribute

1. **Fork the Repository**: Fork [VOXA/VOXA](https://github.com/VOXA/VOXA) on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feat/my-cool-widget
   ```
3. **Make Your Changes**: Keep your changes clean, well-tested, and consistent with the dark glassmorphic design system.
4. **Commit Your Changes**:
   ```bash
   git commit -m "feat: add modern quick-action widget"
   ```
5. **Push and Open a PR**: Push your branch to GitHub and open a Pull Request against the `main` branch.
